# مذكرة التدريب الميداني التفصيلية - عبد القوي
(تكفي لتعبئة 40 صفحة/يوم في الدفتر)

**اليوم الأول**
*   **المهمة:** دراسة النظام اليدوي للعميل.
*   **التفاصيل:** عقد اجتماع مع العميل لدراسة الدفاتر الورقية المستخدمة حالياً في المبيعات والمشتريات وتحديد مشاكل النظام اليدوي.

**اليوم الثاني**
*   **المهمة:** جمع المتطلبات الوظيفية (Functional Requirements).
*   **التفاصيل:** تحديد احتياجات العميل البرمجية بالتفصيل: نظام نقاط بيع (POS)، تتبع المخزون، إدارة الموردين، وإدارة شؤون الموظفين.

**اليوم الثالث**
*   **المهمة:** جمع المتطلبات غير الوظيفية.
*   **التفاصيل:** مناقشة متطلبات الأمان، سرعة الاستجابة، ونوع الاستضافة (سحابية) وتحديد التقنيات التي سيتم استخدامها (PHP/MySQL).

**اليوم الرابع**
*   **المهمة:** صياغة مستند المتطلبات (SRS).
*   **التفاصيل:** كتابة وثيقة متطلبات النظام الشاملة التي تحتوي على نطاق العمل وجميع الميزات المطلوبة لعرضها على العميل.

**اليوم الخامس**
*   **المهمة:** اعتماد خطة المشروع.
*   **التفاصيل:** مراجعة وثيقة الـ SRS مع العميل، الحصول على موافقته النهائية، وتوقيع عقد البدء في برمجة نظام الـ ERP.

**اليوم السادس**
*   **المهمة:** تحليل كيانات النظام.
*   **التفاصيل:** تحديد الكيانات الأساسية لقاعدة البيانات: المستخدمين، العملاء، الموردين، المنتجات، الفواتير، المصروفات.

**اليوم السابع**
*   **المهمة:** تصميم مخطط الكيانات (ERD).
*   **التفاصيل:** رسم مخطط العلاقات باستخدام أداة Draw.io لتوضيح كيفية ارتباط جدول المبيعات بجدول المنتجات والعملاء.

**اليوم الثامن**
*   **المهمة:** إنشاء قاعدة البيانات MySQL.
*   **التفاصيل:** إعداد الخادم المحلي (XAMPP)، والدخول إلى phpMyAdmin لإنشاء قاعدة البيانات تحت اسم `qat_erp`.

**اليوم التاسع**
*   **المهمة:** بناء جداول المستخدمين والصلاحيات.
*   **التفاصيل:** كتابة أوامر SQL لإنشاء جدول `users` وإضافة حقول لاسم المستخدم، كلمة المرور المشفرة، ونوع الصلاحية.

**اليوم العاشر**
*   **المهمة:** بناء جداول الأطراف الخارجية.
*   **التفاصيل:** إنشاء جداول `customers` و `providers` وتحديد المفاتيح الأساسية (Primary Keys) لتسجيل تفاصيل التواصل والأرصدة.

**اليوم الحادي عشر**
*   **المهمة:** بناء جداول المخزون والعمليات.
*   **التفاصيل:** إنشاء جداول `products`، `sales`، و `sales_details` لتخزين الفواتير والأصناف المباعة.

**اليوم الثاني عشر**
*   **المهمة:** بناء جداول المالية والموظفين.
*   **التفاصيل:** إنشاء جداول `expenses` للمصروفات، `debts` للديون، و `staff` لإدارة بيانات الموظفين.

**اليوم الثالث عشر**
*   **المهمة:** تطبيق قواعد البيانات العلائقية.
*   **التفاصيل:** ربط الجداول ببعضها باستخدام المفاتيح الأجنبية (Foreign Keys) لضمان تكامل البيانات (Referential Integrity).

**اليوم الرابع عشر**
*   **المهمة:** إعداد بيئة التطوير (IDE).
*   **التفاصيل:** تنصيب وتجهيز محرر الأكواد VS Code، وتركيب الإضافات المساعدة للغة PHP و HTML و CSS.

**اليوم الخامس عشر**
*   **المهمة:** تهيئة مستودع الأكواد (Version Control).
*   **التفاصيل:** إنشاء مستودع جديد على منصة GitHub، وتجهيز ملف `.gitignore`، ورفع أول نسخة من هيكل المجلدات الأساسية.

**اليوم السادس عشر**
*   **المهمة:** رسم الواجهات (Wireframes).
*   **التفاصيل:** تصميم الهياكل المبدئية لشاشة تسجيل الدخول ولوحة التحكم الرئيسية (Dashboard) لتحديد أماكن القوائم.

**اليوم السابع عشر**
*   **المهمة:** رسم واجهة نقطة البيع (POS).
*   **التفاصيل:** تصميم شاشة المبيعات لتكون سريعة الاستخدام بحيث تحتوي على شريط للبحث عن المنتجات بالباركود وجدول للفاتورة.

**اليوم الثامن عشر**
*   **المهمة:** برمجة القالب الأساسي (HTML/CSS).
*   **التفاصيل:** تجهيز ملف `index.php` وتصميم صفحة تسجيل الدخول باستخدام مكتبات CSS متجاوبة لتعمل على الأجهزة المختلفة.

**اليوم التاسع عشر**
*   **المهمة:** برمجة هيكل لوحة التحكم.
*   **التفاصيل:** فصل أجزاء التصميم المشتركة إلى ملفات مستقلة في مجلد `includes/` (مثل Header, Footer, Sidebar) لتسهيل استدعائها.

**اليوم العشرون**
*   **المهمة:** ربط النظام بقاعدة البيانات.
*   **التفاصيل:** إنشاء ملف `config/database.php` وكتابة كود الاتصال بقاعدة البيانات MySQL باستخدام تقنية PDO لضمان الأمان.

**اليوم الحادي والعشرون**
*   **المهمة:** برمجة نظام تسجيل الدخول.
*   **التفاصيل:** برمجة `login.php` لاستقبال بيانات المستخدم، مطابقتها مع قاعدة البيانات، وبدء جلسة آمنة (PHP Session).

**اليوم الثاني والعشرون**
*   **المهمة:** برمجة حماية الصفحات.
*   **التفاصيل:** كتابة كود للتحقق من الجلسة في بداية كل صفحة وتوجيه المستخدم غير المصرح له إلى `access_denied.php`.

**اليوم الثالث والعشرون**
*   **المهمة:** برمجة شاشة إدارة العملاء.
*   **التفاصيل:** تصميم وتطوير `customers.php` لعرض قائمة العملاء من قاعدة البيانات في جدول تفاعلي.

**اليوم الرابع والعشرون**
*   **المهمة:** إضافة عمليات العملاء (CRUD).
*   **التفاصيل:** برمجة النماذج المخصصة لإضافة عميل جديد، تعديل بياناته، وحذفه مع مراعاة تحديث الصفحة ديناميكياً.

**اليوم الخامس والعشرون**
*   **المهمة:** برمجة وحدة الموردين.
*   **التفاصيل:** تطوير `providers.php` وتسجيل الموردين وبرمجة صفحة كشف الحساب `provider_statements.php`.

**اليوم السادس والعشرون**
*   **المهمة:** تطوير وحدة المنتجات.
*   **التفاصيل:** برمجة `manage_products.php` لإضافة الأصناف، تحديد أسعار البيع والشراء، ورفع صور للمنتجات.

**اليوم السابع والعشرون**
*   **المهمة:** برمجة منطق المخزون.
*   **التفاصيل:** كتابة استعلامات لعرض الرصيد الحالي لكل منتج وتنبيه الإدارة عند انخفاض الكميات.

**اليوم الثامن والعشرون**
*   **المهمة:** برمجة واجهة المبيعات الأمامية.
*   **التفاصيل:** تحويل واجهة المبيعات في `sales.php` لتكون تفاعلية باستخدام JavaScript (إضافة أسطر للفاتورة دون تحديث الصفحة).

**اليوم التاسع والعشرون**
*   **المهمة:** برمجة العمليات الخلفية للمبيعات.
*   **التفاصيل:** برمجة الكود المسؤول عن استلام بيانات الفاتورة (عبر POST) وحفظها في جدولي `sales` و `sales_details`.

**اليوم الثلاثون**
*   **المهمة:** برمجة خصم المخزون.
*   **التفاصيل:** ربط عملية حفظ فاتورة المبيعات باستعلام (UPDATE) يقوم بخصم كميات الأصناف المباعة من جدول المنتجات آلياً.

**اليوم الحادي والثلاثون**
*   **المهمة:** تطوير وحدة المشتريات.
*   **التفاصيل:** برمجة `purchases.php` لإدخال فواتير المشتريات وتحديث تكلفة المنتجات بناءً على الأسعار الجديدة للمورد.

**اليوم الثاني والثلاثون**
*   **المهمة:** برمجة زيادة المخزون.
*   **التفاصيل:** برمجة العملية العكسية للمبيعات، حيث تزيد الكميات في المخزون تلقائياً بمجرد اعتماد فاتورة المشتريات.

**اليوم الثالث والثلاثون**
*   **المهمة:** تطوير إدارة المصروفات.
*   **التفاصيل:** برمجة صفحة `expenses.php` لإتاحة تسجيل المصروفات التشغيلية اليومية بتصنيفاتها المختلفة.

**اليوم الرابع والثلاثون**
*   **المهمة:** برمجة إدارة الديون.
*   **التفاصيل:** تطوير `debts.php` لربط المبالغ المتبقية من فواتير المبيعات بحسابات العملاء، وبرمجة نظام التحصيل.

**اليوم الخامس والثلاثون**
*   **المهمة:** تطوير إدارة الموظفين والحضور.
*   **التفاصيل:** برمجة `staff.php` و `attendance.php` لإضافة الموظفين وتسجيل حضورهم وغيابهم اليومي وسلفهم.

**اليوم السادس والثلاثون**
*   **المهمة:** تطوير وحدة المرتجعات.
*   **التفاصيل:** برمجة صفحات `returns.php` و `refunds.php` لمعالجة إرجاع بضاعة واسترداد المبالغ وإعادتها للمخزون.

**اليوم السابع والثلاثون**
*   **المهمة:** برمجة تقارير النظام.
*   **التفاصيل:** تطوير صفحة `reports.php` لإنشاء تقارير يومية وشهرية مخصصة للبحث حسب التواريخ.

**اليوم الثامن والثلاثون**
*   **المهمة:** برمجة لوحة الإحصائيات (Dashboard).
*   **التفاصيل:** كتابة استعلامات في `admin_dashboard.php` لاستخراج مجاميع الأرباح، المبيعات والمصروفات وعرضها كإحصائيات.

**اليوم التاسع والثلاثون**
*   **المهمة:** رفع النظام إلى الاستضافة (Deployment).
*   **التفاصيل:** حجز الاستضافة المشتركة، الدخول إلى لوحة cPanel، رفع الملفات وتصدير قاعدة البيانات MySQL إلى الخادم الحي.

**اليوم الأربعون**
*   **المهمة:** دمج الفريق وبدء مرحلة الاختبار.
*   **التفاصيل:** دعوة الفريق (محمد، قصي، عبدالرحمن، عمر) للعمل. عمل اجتماع وتوزيع المهام الأمنية والوظيفية لضمان جودة النظام قبل التسليم.
